# EP timing metric correction

The initial preview placed clean end-to-end TPOT next to a non-attention MLP span from a **different instrumented execution**. For C30/env2/B8 case0 BR, clean TPOT was 0.451557 s/token, while the diagnostic execution's own total TPOT was 0.500436 s/token. Therefore the old non-attention value of 0.465817 s/token could exceed clean TPOT without representing an impossible within-run decomposition. It also selected the rank with the largest MLP span, which could differ from the rank determining full step latency.

The requested second metric is narrower: expert execution plus expert dispatch/return communication. For each diagnostic decode step, select the rank with the largest **complete phase span**. On that same rank, sum the exclusive spans named `moe.expert_compute` for expert execution and `moe.forward_a2a`, `forward_token_a2a_submit`, `moe.forward_complete`, `moe.return_a2a`, and `return_token_a2a` for dispatch/return. The sum is the **EP span**. These scopes are exclusive in the current-stream partition, so nested spans are not double-counted. Attention, controller, metadata, and explicit H2D scopes are omitted. Diagnostic total TPOT is reported alongside EP span to establish the within-run denominator. Clean full TPOT remains the primary performance result and includes attention.

The EP span is a critical-rank runtime interval, not a pure CUDA kernel or network service measurement. It can contain host submission gaps, peer waiting, and implicit dependencies on H2D. It cannot be subtracted from the separate clean TPOT. No model rerun is needed: all corrections derive from preserved rank-level diagnostic segments and boundary timestamps. The reporting script validates that the sum of phase spans matches diagnostic wall TPOT within 1%.

For the same C30/env2/B8 case0 BR example, the corrected values are clean full TPOT **0.451557**, paired diagnostic full TPOT **0.500436**, expert execution **0.1999**, dispatch/return **0.1198**, and EP span **0.3197** seconds/token. The original 0.465817 value is retained only as historical context in the raw diagnostic receipt.
